=================== SLIDE 6 ===================
  # Problem Identification
  # ❖Existing portfolio systems rely on static rule-based models such as Merton that assume constant market parameters, failing to adapt to volatile or crisis regimes.
  # ❖Classical strategies have no mechanism to learn from market experience - they recompute weights with fixed formulae regardless of evolving market conditions.
  # ❖Most research tools are Python scripts inaccessible to non-technical investors; there is no interactive interface for parameter exploration or real-time strategy comparison.
  # ❖There is no unified platform for side-by-side comparison of AI-driven (RL) and classical portfolio strategies with live market data and performance metrics.
  # ❖Current RL systems lack explainability and investor trust - investors cannot understand why the AI chose a specific allocation, reducing real-world adoption.

=================== SLIDE 9 ===================
  # Module 2 : User Login & Authentication
  # The User Login & Authentication module provides a secure identity layer that gates access to personalised portfolio features.
  # Only authenticated users can access the Portfolio Tracker and Parameter Tuning Panel.
  # The system uses industry-standard cryptographic practices to ensure that user credentials and session data are protected at all times.
  # Key Features:
  # •  Registration flow collects username, email, and password; passwords are hashed using bcrypt with adaptive salt rounds before being stored in the database.
  # •  Login flow verifies the submitted password against the stored bcrypt hash; on success, a signed JSON Web Token (JWT) is issued with a configurable expiry window.
  # •  All protected API routes validate the JWT on every request; expired or tampered tokens are rejected with a 401 Unauthorized response, forcing re-authentication.
  # •  Session management routes the authenticated user to their dedicated Portfolio Tracker workspace, resolving their account record and personal NAV history from the database.
  # ⚙ Tech Stack:  Flask / FastAPI (backend)  |  bcrypt (password hashing)  |  JWT (session tokens)  |  SQLite / PostgreSQL

=================== SLIDE 10 ===================
  # Module 3 : Live Market Data Integration
  # The Live Market Data Integration module replaces the static Excel input file with a fully automated, real-time data pipeline.
  # On every session or scheduled refresh, the system fetches the latest daily closing prices for NIFTY 50 and NASDAQ-100, computes all 13 RL state features in-memory, and passes the updated state vector directly to the PPO agent - eliminating any manual data collection or Excel maintenance.
  # Key Features:
  # •  yfinance API pulls daily OHLCV data for ^NSEI (NIFTY 50) and ^NDX (NASDAQ-100); historical data from a configurable lookback window (default: 2 years) is downloaded automatically.
  # •  All 13 RL state features are computed in-memory using Pandas: log returns, 20-day & 60-day rolling volatility, drawdown from running max, rolling Sharpe ratio, and volatility regime flag.
  # •  The live RL state vector is fed to the trained PPO model, which outputs 'Today’s Recommended Allocation' (% NASDAQ, % NIFTY, % Cash) displayed on the dashboard.
  # •  A data quality validation step detects gaps or NaN values in the live feed and applies forward-fill imputation to ensure continuous, uninterrupted model inference.
  # ⚙ Tech Stack:  yfinance (market data API)  |  Pandas (feature engineering)  |  NumPy  |  APScheduler (scheduled refresh)

=================== SLIDE 11 ===================
  # Module 4 : RL Working Process
  # The RL Working Process module is the core intelligence engine of Dynamic Portfolio Rebalancing using Reinforcement Learning
  # A Proximal Policy Optimization (PPO) agent is trained on historical NIFTY 50 & NASDAQ-100 data using a custom Gymnasium environment.
  # The agent learns to dynamically allocate portfolio weights across three assets by maximising a multi-objective reward that balances return, risk-adjusted performance, downside protection, and transaction cost efficiency.
  # Key Features:
  # •  State Space (13 features): Log Returns, Vol20, Vol60, Drawdown, Volatility Regime, Rolling 60-day Return, and Rolling Sharpe Ratio - computed separately for both NIFTY and NASDAQ.
  # •  Action Space: 3 raw logits from the PPO MLP [256 -128 - 64] pass through Softmax to produce non-negative portfolio weights summing to 1: (w_NASDAQ, w_NIFTY, w_Cash).
  # •  Multi-objective Reward:  r_portfolio + α·Sharpe − λ₁·|Drawdown| − λ₂·Turnover (α=0.5, λ₁=2.0, λ₂=0.1); transaction cost of 0.1% deducted on every rebalancing step.
  # •  Training: 100,000 PPO timesteps with learning rate 3×10⁻⁴, n_steps=2048, batch_size=64, γ=0.99; model weights saved and loaded for live inference without retraining.
  # ⚙ Tech Stack:  Stable-Baselines3 (PPO)  |  Gymnasium (custom PortfolioEnv)  |  PyTorch (neural network backend)

=================== SLIDE 13 ===================
  # Module 6 : Strategy Parameter Tuning Panel
  # The Strategy Parameter Tuning Panel transforms Dynamic Portfolio Rebalancing using Reinforcement Learning from a fixed model into an interactive simulation workbench.
  # Users can adjust key financial and RL parameters through intuitive sliders and dropdowns, then immediately re-run the strategy to observe how changes affect portfolio performance - all without touching any code.
  # This makes the platform valuable as both an educational tool and a practical research environment.
  # Key Features:
  # •  Risk Aversion slider (γ: 1-10) controls the Merton model’s conservatism; lower γ produces higher equity allocation, higher γ shifts weight toward cash.
  # •  Transaction Cost Rate slider (0.0% - 0.5%) adjusts the per-rebalance cost applied to both strategies, enabling sensitivity analysis on turnover efficiency.
  # •  Risk-Free Rate (rf) dropdown (5% - 8% p.a.) updates the Sharpe ratio baseline and Merton weight formula, reflecting different prevailing interest rate environments.
  # •  Dual Execution Modes: Autonomous PPO (full auto-pilot - agent rebalances without asking) and Advisory Mode (AI recommends weights - user reviews and approves before execution).
  # ⚙ Tech Stack:  Streamlit (sliders + dropdowns)  |  PPO re-inference (Stable-Baselines3)  |  Plotly (live chart update)
